# AI Job Scraper & Resume Matcher

## Overview

AI-powered job matching application that analyzes a user's resume
and matches it with relevant job opportunities based on skills,
experience, and job requirements.

## Problem Statement

Finding suitable jobs manually can be time-consuming. This application
uses Generative AI to analyze resumes and job descriptions and help
users identify relevant opportunities.

## Features

- Resume upload and analysis
- Job search and filtering
- AI-powered resume analysis
- Job-resume matching
- Match percentage/score
- Matching skills identification
- Missing skills identification
- AI-generated improvement recommendations
- User-friendly web interface

## How It Works

1. User uploads their resume.
2. The application extracts the resume information.
3. Job listings are analyzed.
4. Resume skills are compared with job requirements.
5. AI generates a compatibility score.
6. The application displays matching skills and missing skills.
7. AI provides recommendations for improving the candidate profile.

## Generative AI

Generative AI is used to analyze resume content and job descriptions,
identify relevant skills, evaluate compatibility, and generate
personalized recommendations.

## Technology Stack
